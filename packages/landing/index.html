llm.rs GitHub

Train ML models from CSV, on your own machine.

llm.rs handles classification, regression, semi-supervised self-training, clustering, anomaly detection, and offline reinforcement learning — then exports a portable ONNX model. No cloud, no account, no notebooks.

View on GitHub Use the CLI
llm train --task classification … 
$ llm dataset data/iris.csv
registered dataset 3f2a91c7 (150 rows, 5 columns)

$ llm train --dataset-id 3f2a91c7 --task classification \
    --algorithm logistic_regression \
    --features sepal_length,sepal_width,petal_length,petal_width \
    --label species
job 8c1d04e2 completed · accuracy 0.973 · f1 0.968

$ llm export --job-id 8c1d04e2 --output model.onnx
wrote model.onnx (12.4 KB)

Everything happens locally.

Your CSV and trained artefacts never leave your machine. Datasets, jobs, metrics, and models persist to local SQLite storage.

Six task types

Classification, regression, semi-supervised, clustering, anomaly detection, and offline RL share one workflow.

Local-first and private

No uploads, no API keys, no accounts. Everything persists to a local SQLite database on your disk.

ONNX is the contract

Every successful job exports a portable .onnx model that runs in any ONNX-compatible runtime, independent of the training code.

Two surfaces, one engine

A native desktop app for the visual workflow, or the llm CLI for scripts and headless training — same Rust core underneath.

Or drive it from the terminal.

The llm CLI registers datasets, trains models, inspects jobs, and exports artefacts — built with Cargo from the same workspace.

llm train --task classification … 
cd crates
cargo build --release -p llm-cli

./target/release/llm dataset data/iris.csv
./target/release/llm train \
  --dataset-id <id> \
  --task classification \
  --algorithm logistic_regression \
  --features sepal_length,sepal_width,petal_length,petal_width \
  --label species
./target/release/llm job <job-id>
./target/release/llm export --job-id <job-id> --output model.onnx

Desktop builds for macOS, Windows, and Linux are on the releases page.
